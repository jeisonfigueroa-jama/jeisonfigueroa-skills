# Repository guidance

This repository contains Jeison Figueroa's public personal skills plugin.

- Edit source skills under `plugins/jeisonfigueroa/skills/<skill-name>/SKILL.md`.
- Keep marketplace name `jeisonfigueroa-skills` and plugin name `jeisonfigueroa` consistent with installation examples.
- Keep each skill focused, with precise YAML `name` and `description`. Add supporting files only when useful.
- Update the README skill list when adding or removing skills. Increment the plugin version for changed releases.
- Validate JSON manifests, skill frontmatter, referenced paths, and any changed executable helpers before publishing.
- Keep secrets and private company or customer content outside this public repository.
